# Synthetic fixtures (Ryan's lane)

One folder per source id (matches `sources.id` in `src/db/schema.ts`), in each platform's
real export shape as closely as `docs/sources/<id>.md` documents it. Fake data only —
generated by `scripts/gen-source-fixtures.py` (seeded, deterministic — rerun it any time
to regenerate identical files).

A monthly file for `2026-09` per source; daily files `2026-10-01` … `2026-10-03` for the
four daily-capable sources (amazon, ebay, shopgoodwill, upright) — the ones that feed the
nightly pulse.

## Deliberate messy cases

| Case | Where |
|---|---|
| Preamble/disclaimer lines before the real header row | `amazon/amazon_2026-09.csv` (3 lines + blank line above the header) |
| A refund as its own negative line, not an edit to the order | `amazon/amazon_2026-09.csv` (row 7, order `111-2200005-3344561`); `fedex/fedex_2026-09.csv` (the `Refund - Home Delivery` line) |
| An order right at the midnight-Eastern business-date boundary | `shopgoodwill/shopgoodwill_2026-10-02.csv`, item `SG-88350`, `End Date = 2026-10-02T04:05:00Z` (= 00:05 America/Indiana/Indianapolis on 10-02 — tests that `business_date` derivation uses the Goodwill timezone, not UTC) |
| A renamed column vs. the monthly file's header | `ebay/ebay_2026-10-03.csv` — `Sold For` renamed to `Sale Amount` |
| The same sale reported by two sources (Upright spans channels) | `ebay/ebay_2026-10-02.csv` order `03-8899001` **=** `upright/upright_2026-10-02.xlsx` row with `Channel = eBay`, `Channel Order ID = 03-8899001` — tests `dedupe_key = channel + ':' + channel_order_id + ':' + channel_item_id` |

- `shipping_osm_pb_easypost/` holds **four** files, not one: `easypost_2026-09.csv`,
  `pitneybowes_2026-09.csv`, `osm_2026-09.csv`, and `bank_1st_source_0101_2026-09.csv` —
  three carrier exports plus the bank statement line that may actually be the real
  source of truth (see the Gotchas in that source doc).

  everything else is `.csv`.
- `goodwill_books/goodwill_books_2026-09.csv` is shaped like the statement Goodwill
  actually receives (header block, then a line-item table, then a payment total) rather
  than a plain flat export — the real thing is an email attachment, not a portal download.

  source docs) — no public sample exists for any of the three. Swap these for real
